# Canonical skills

These are the canonical `ai-config` skills. Each is explicitly invoked in Codex with its `$aic-*` name and installed as two managed files under the Codex user skill root. Phase 8 adds two adapted 21st capabilities and one native visual-review capability; their local instructions remain authoritative.

Skills provide focused procedures. The [standards](../standards/README.md) remain the durable cross-project rules.
