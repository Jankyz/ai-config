# Standards

These provider-neutral standards are the canonical rules for `ai-config` workflows.
They define durable constraints; skills provide the task-specific procedure.

- [Global agent contract](global-agent-contract.md) is the compact, always-loaded baseline.
- [Planning](planning.md) defines when a change may be authorized.
- [Execution](execution.md) defines approved-plan delivery boundaries.
- [Verification](verification.md) defines evidence-based completion.
- [Commits](commits.md) defines explicit Lore commit ownership.
