# Verification standard

Completion requires evidence, not confidence. Derive relevant checks from the approved plan and definition of done.

Use the smallest proof set that establishes each success condition, such as tests, type checks, linting, builds, static analysis, runtime checks, security review, or required manual verification.

Read and report exact results. A failed check returns work to implementation unless the plan explicitly requires an owner decision. State known verification gaps and any manual gate precisely.

Do not claim completion when required evidence has not been collected.
