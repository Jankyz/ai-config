# Execution standard

Begin a material implementation only from an approved plan with no material open decisions. Read the plan and relevant project instructions before mutation.

Work autonomously on ordinary, reversible steps inside the approved scope. Preserve user-owned and unknown content, avoid speculative abstractions and dependencies, and reuse established project patterns.

Stop the affected branch for a newly discovered material decision, unsafe/destructive operation, required manual gate, or evidence that invalidates the plan. Report the facts, options, recommendation, trade-offs, and required decision.

Do not commit, publish, release, or expand into a later phase without separate explicit authorization.
