# Architecture documentation

This directory contains durable, project-wide architectural decisions and invariants.

- [AI Config Master Architecture v1](AI-CONFIG-MASTER-ARCHITECTURE-V1.md) is the canonical approved
  architecture baseline.

Architecture documents state durable decisions; approved implementation plans in `docs/plans/`
authorize bounded delivery work. Documents identify their status (for example, draft or approved).
Material architecture changes require owner approval before implementation relies on them.
